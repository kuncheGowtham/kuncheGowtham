## Selected work

### [Bandgap Voltage Reference](https://github.com/kuncheGowtham/Design-of-a-Bandgap-Voltage-Reference-Circuit)

Temperature-compensated analog IC design producing an approximately 1.2 V reference for power management and mixed-signal applications. The work combines CTAT and PTAT voltage generation with current-mirror biasing.

### [FuelTopUp](https://github.com/kuncheGowtham/FuelTopUp)

An on-demand fuel delivery platform built with Python, Flask, SQLite, HTML, CSS, and JavaScript. Includes location-based ordering, authentication, delivery tracking, and dedicated customer and provider dashboards.

### [Electronic Dice](https://github.com/kuncheGowtham/Electric-Dice-Auduino)

An Arduino-based embedded project that generates a random value from one to six and renders it through an LED dice pattern.
